==========================================
DÉPANNAGE
==========================================

Probleme : "Chargement..." bloque
Solution : Verifier F12 > Console pour les erreurs

Probleme : "Email not confirmed"
Solution : Executer dans Supabase SQL Editor :
UPDATE auth.users SET email_confirmed_at = NOW() WHERE email = 'votre@email.com';

Probleme : "SupabaseService is not defined"
Solution : Verifier que supabase-client.js est charge

Probleme : Formulaire vide
Solution : Creer une cage dans Supabase Table Editor
