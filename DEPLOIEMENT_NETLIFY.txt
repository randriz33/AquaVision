==========================================
ETAPE 1: CONNEXION A NETLIFY
==========================================

1. Ouvrez votre navigateur
2. Allez sur: https://app.netlify.com
3. Connectez-vous (ou creez un compte gratuit)
   - Vous pouvez vous connecter avec GitHub (recommande!)
   - Ou avec email

==========================================
ETAPE 2: IMPORTER LE PROJET
==========================================

1. Sur le dashboard Netlify, cliquez:
   "Add new site" (bouton en haut)

2. Selectionnez:
   "Import an existing project"

3. Choisissez:
   "Deploy with GitHub"

4. Autorisez Netlify a acceder a GitHub
   (Une fenetre GitHub va s'ouvrir)
   - Cliquez "Authorize Netlify"

==========================================
ETAPE 3: SELECTIONNER LE REPOSITORY
==========================================

1. Dans la liste, recherchez: "AquaVision"
   ou tapez: randriz33/AquaVision

2. Cliquez sur le repository "AquaVision"

==========================================
ETAPE 4: CONFIGURATION DU DEPLOIEMENT
==========================================

Netlify va detecter automatiquement le fichier netlify.toml

Vous devriez voir:
- Branch to deploy: main
- Build command: echo 'No build needed - static site'
- Publish directory: public

SI ces champs sont vides, remplissez:
- Base directory: (laissez vide)
- Build command: (laissez vide ou "echo 'Static site'")
- Publish directory: public

==========================================
ETAPE 5: DEPLOYER
==========================================

1. Cliquez le bouton: "Deploy AquaVision"
   (ou "Deploy site")

2. Attendez 1-2 minutes
   - Vous verrez les logs de deploiement
   - Le site se construit automatiquement

3. Quand c'est termine, vous verrez:
   "Site is live"

==========================================
ETAPE 6: RECUPERER L'URL
==========================================

Netlify va generer une URL automatique:
Format: https://nom-aleatoire-123.netlify.app

1. Copiez cette URL complete
2. Revenez dans Claude Code
3. Tapez: "deploiement reussi" et collez l'URL

==========================================
ETAPE 7: PERSONNALISER L'URL (OPTIONNEL)
==========================================

Vous pouvez changer l'URL generee:

1. Sur le dashboard du site, cliquez "Site settings"
2. Allez dans "Domain management"
3. Sous "Custom domains", cliquez "Options"
4. Choisissez "Edit site name"
5. Entrez: aquavision-pro (ou autre nom disponible)
6. L'URL deviendra: https://aquavision-pro.netlify.app

==========================================
APRES LE DEPLOIEMENT
==========================================

Une fois le deploiement reussi:

1. Testez l'application en ligne
   - Ouvrez l'URL Netlify
   - Essayez de vous connecter
   - Verifiez que tout fonctionne

2. Configuration Supabase (IMPORTANT!)
   - Allez sur: https://supabase.com/dashboard/project/gswozuotdrfgvutitssf
   - Authentication > URL Configuration
   - Ajoutez l'URL Netlify dans:
     * Site URL
     * Redirect URLs
   - Sauvegardez

3. Re-testez l'authentification

==========================================
EN CAS DE PROBLEME
==========================================

PROBLEME: Le deploiement echoue
SOLUTION: Verifiez les logs dans Netlify, cherchez les erreurs

PROBLEME: Page blanche apres deploiement
SOLUTION: Verifiez que le Publish directory est bien "public"

PROBLEME: Fichiers non trouves (404)
SOLUTION: Verifiez que index-supabase.html existe dans public/

PROBLEME: Authentification ne marche pas
SOLUTION: Verifiez que l'URL Netlify est ajoutee dans Supabase
