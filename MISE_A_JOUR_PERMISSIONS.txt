==========================================
MISE A JOUR DES PERMISSIONS
==========================================

PROBLEME ACTUEL:
Seuls les admins peuvent creer des cages.
Les techniciens ne peuvent pas entrer toutes les donnees.

SOLUTION:
Executer le fichier SQL de mise a jour pour donner
les bonnes permissions aux techniciens.

==========================================
ETAPES A SUIVRE
==========================================

1. Allez sur Supabase:
   https://supabase.com/dashboard/project/gswozuotdrfgvutitssf

2. Cliquez sur "SQL Editor" dans le menu de gauche

3. Cliquez sur "New query"

4. Ouvrez le fichier:
   database/update_permissions_techniciens.sql

5. Copiez tout le contenu du fichier

6. Collez dans l'editeur SQL Supabase

7. Cliquez "Run" (ou F5)

8. Verifiez le message de succes

==========================================
NOUVELLES PERMISSIONS
==========================================

TECHNICIENS PEUVENT:
✓ Voir toutes les cages
✓ Creer des cages
✓ Modifier les cages (mettre a jour population, etc.)
✓ Creer des rapports journaliers
✓ Modifier leurs propres rapports
✓ Ajouter des echantillons biometriques
✓ Enregistrer les mortalites
✓ Entrer tous les parametres environnementaux
✓ Creer des alertes

TECHNICIENS NE PEUVENT PAS:
✗ Supprimer des cages (reserve aux admins)

ADMINS PEUVENT:
✓ Toutes les permissions des techniciens
✓ Supprimer des cages
✓ Modifier tous les rapports (pas juste les leurs)
✓ Gerer l'inventaire des aliments
✓ Gerer les objectifs de production
✓ Voir tous les logs d'activite de tous les utilisateurs

==========================================
APRES LA MISE A JOUR
==========================================

Une fois les permissions mises a jour:

1. Les techniciens pourront creer des cages directement
   depuis leur dashboard

2. Ils pourront modifier les informations des cages

3. Toutes les fonctionnalites de saisie seront accessibles

4. Pas besoin de redemarrer l'application
